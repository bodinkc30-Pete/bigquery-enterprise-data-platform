# Public Publication Boundary

This is a clean, history-free portfolio publication derived from the private working project.

## Included
- Representative BigQuery/dbt/SQL/Terraform engineering code
- Synthetic and portfolio-safe datasets
- Curated public evidence
- Privacy-safe architecture and validation artifacts

## Intentionally excluded
- Raw company files or raw operational exports
- PII and real financial identifiers
- Confidential client metrics and deep operational detail
- Source inventory that exposes internal filenames/workflows
- Credentials, local paths, cloud secrets, private runtime logs
- Private Git history and internal handoff notes

The canonical working repository remains private. This public edition exists so recruiters and interviewers can inspect the engineering implementation safely.
